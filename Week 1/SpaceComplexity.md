# Space Complexity

## Introduction

**Space complexity** is the amount of memory an algorithm requires to execute as a function of the input size.

Like time complexity, space complexity helps us compare algorithms and understand how their memory requirements grow as the input size increases.

Space complexity is generally expressed using **asymptotic notation**, such as:

- O(1) — Constant Space
- O(n) — Linear Space
- O(n²) — Quadratic Space

---

## Why Analyze Space Complexity?

Space complexity helps us understand:

- How much memory an algorithm requires.
- How memory usage grows with the input size.
- Whether an algorithm can handle large inputs within available memory.
- The trade-off between time and memory when comparing algorithms.

---

## Time Complexity vs Space Complexity

### Time Complexity

**Time complexity** measures how the running time of an algorithm grows with the input size.

For example, traversing an array of `n` elements requires:

```text
O(n)
```
